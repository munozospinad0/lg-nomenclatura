# lg-nomenclatura

Contenido **cifrado**. Todo lo que hay aqui son paginas y audios cifrados con
AES-256-GCM; la llave se deriva de una clave con PBKDF2-SHA256.
Sin la clave no hay nada legible en este repositorio.

Se genera desde el proyecto fuente con `node scripts/empaquetar.mjs`.
No editar nada de aqui a mano.
